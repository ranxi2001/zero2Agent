第一部分：面试问题
1. 最近一年你的agent学习路线是什么，接触过哪些比较好的agent产品？

2. 你用过trae、claude code、codex，这几个agent之间的优劣势？

3. 你如果去评价一个agent的能力，不考虑模型，你怎么去评价？

4. 在一些场景下可能会对模型的选型做出限制。针对不同的模型，去优化一个agent在全流程的表现，你的方法论是什么？

5. 真实的业务场景下，一类agent的需求通常是收敛的，你需要对agent在特定场景上做优化，你有什么优化的思路吗？RAG是一种处理手段，那如果agent的任务里不仅是在知识库检索，还包含写脚本、写SQL之类的任务，你还有什么处理方法？

6. skill的目录结构是什么样的？skills相对于MCP的最大优点是什么？MCP也能封装工具，搭建生态，还有什么其它优点？假如你要给一群完全不懂技术的人装openclaw，你会用什么方法？

7. claude code检索代码的方式？为什么早期用RAG，后来又不用了？

第二部分：拷打项目

1. embedding模型的选型是怎么选的？

2. rag切分的粒度是怎么定的？具体是怎么实现的？

3. 你用了redis streams，为什么这么选型？

4. 了解过数据库的性能上限吗？
