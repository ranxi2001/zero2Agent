字节面经 硕一
两周半 全流程走完，感觉已经很快了，但还是这么久，每天都是约晚上9点后的面试，这就是工作之后的跳槽成本很高的原因吧，每天当贼一样面试😂
，也祝各位校招师弟拿到想要的offer。欢迎来找我聊ai时代的职业规划，大家抱团取暖，共度寒冬！

6.29 1面，  5min 通过。 约下一面
7.1二面。 7.2 约三面。 
7.5 周末三面。 
7.6 第一次沟通。
7.7 约加面。
7.9 加面。 面完秒通过， 7.10 hr面。 
7.13 中午流水收集。 晚上沟通薪资，已经很满意了，直接接了。
7.15 offer letter。 

一面：
20min， + leetcode。
agent项目：
1. 整体脉络
2. 幻觉问题怎么解决的？
3. 你们的多租户问题怎么处理的？ 
4. 你们现在有多少
5. 你们ai coding 提效多少？ 
6. 平时 写代码用啥？ 

会员业务：
1. 缓存过期咋办？
2. 你们这里调用了b端接口？ 怎么处理了？ 
3. 你们入会的信息怎么保存的？ 怎么能保证快速查询？ 追问： 怎么查一个人的所有会员卡（答： 这个qps低， mysql扛得住）？ 
4. 你说你们的集群是异地多活的？ 两边数据不一致怎么办？
5. 你们身份标签的 更新频率多少？ 多久能读到？
6. 常用哪些身份标签？ 怎么降低不断增加的标签成本？
7. 你们这里ai 创新做了什么？
8. 会员身份接口没有返回怎么办？
9. 最高的tps 多少？ （60w） 怎么能抗住的？ 
10. 这里有什么稳定性风险？ 你能想到什么？ 

手撕：
简单题， 最长连续不重复子串。 

二面：
10min 聊天， 因为之前约面的时候接触过 简单聊了一下后开始做题。 
1. 这几个项目你都讲讲吧， 过程中问了一些细节跟个人的思考。
2. 你的绩效咋样？ 假如说现在你是来述职的，你会咋讲这些事情？ 
3. 你们 ai 提效咋样，代码生成率100%？ 需求提效有多少？ 
4. 如何识别系统的 稳定性风险

写个线程安全的阻塞队列。  （vibe coding 太久了， 锁啥的都不会写了。写了个只有一点点像的代码，，，
写个 带小数点 的字符串的乘法。 

1. 能不能来北京？
2. 个人发展规划是咋样的？
3. 最快什么时候能到岗？ 

三面：
聊天局， 简单算法。 第二天沟通了一下意向，第三天沟通想加一面。
1. 为啥1年考虑换工作了？ 你对新工作有什么期望。
2. 讲讲你们干的事情。 
3. 你现在工作强度？
4. 你们的agent有什么功能？
5. 你们的agent 有多智能？ 重复执行任务怎么办？
6. 你们的agent 有登录态？ 怎么解决的？ 沙箱里怎么写入？ 怎么处理越权问题？ 
7. Agent 怎么处理可能的恶意用户？ 你们的权限怎么分配的？
8. 这里为啥要用多agent？ 平时啥时候会用多agent？ 
9. Agent执行超时怎么办？ agent胡说八道怎么办？ 你们的钉钉渠道跟网页端都有agent入口？ 对应的是同一个agent？ 怎么处理不同渠道的显示？ 
10. 你对ai coding 怎么看？

螺旋数组。

加面：
本来要做题的， 面试官不知道啥情况， 给我出不了题， 说，算了，  问问问题吧。  40min。 

1. Hr说昨晚你压测值班？ 你们压测怎么测？
2. 如果redis 的cpu占用突然100%， 但是接口无报错，通常是因为什么？
3. 还处理过什么事情？
4. 你们的ai产品用户是谁？ 
5. 你们这里是怎么决定优惠额度的？
6. 你们的系统瓶颈在哪里？ （流量） 如何优化？ 圈人。 你们的圈人系统工作流程讲讲
7. 怎么理解agent 的注意力？ 上下文是什么意思？ 
8. 有设计memory 吗？ 做的话你会考虑什么？ 你了解业界最新的这块内容咋做的吗？
9. 再回来讲讲你刚才说的圈人？ 离线 表怎么能支撑c端的高qps？ 如果要加个标签的话流程是怎么样的？
10. 怎么证明你们的优化是有效的？ ab实验一般怎么设计

之前都没问过你啥基础知识， 你的技术栈是什么？ Java？
1. 讲讲垃圾回收机制，
2. 如果要修改多个数据库表怎么办？ 都用事务吗？ 跨库怎么办？
3. 讲一讲主从复制用到了什么日志？ 只用到了binlog吗？ （当时面试官说还有一个啥的我给忘了， 我反问了这个是用于解决多写入时候的冲突问题的吗？）
4. 讲一讲redis 如果断电了 怎么恢复？ 你觉得为啥要用两个日志？ 有没有更本质的原因？ （写入时延）
5. 线程池一般怎么控制参数？ 你知道协程吗？
6. Java的运行内存有哪些？ 你怎么理解堆和栈？ 你知道 在数据层面上的二者本质区别吗？ 
7. Java 的hash表是什么？ 这是怎么设计的？
8. 讲一讲 redis 的常用数据结构？
9. …
10. 有一些都记不得了，这里基本就是对知识掌握情况摸底了。
