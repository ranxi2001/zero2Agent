字节Agent一面 轻松上岸
#秋招# 字节Agent一面己顺利通过  老哥刚开始是挺紧张的 在我的帮辅助下回答的很流畅 全程都在帮忙 分享下

1. 多模态结构：视觉编码器提取特征，经适配器对齐后喂给LLM。通常先对齐再微调。
2. RAG流程：离线建库（切分+向量化）→ 在线检索（召回+精排）→ 增强生成（拼Prompt）。
3. LoRA vs QLoRA：LoRA训旁路低秩矩阵；QLoRA把底座4bit量化，省显存且保精度。
4. A2A与MCP：MCP是AI的USB接口（连工具），A2A是Agent间协议（搞协作）。
5. 长上下文：可用位置编码扩展、KV Cache压缩。知识类任务直接上RAG检索更优。
6. 常用框架：LangChain搭原型，LangGraph搞复杂状态，LlamaIndex做检索，AutoGen搞多智能体，Dify低代码。
7. 多模态检索：核心是CLIP跨模态Embedding（以文搜图），也可结合OCR转文本混合检索。
8. 信息存储：用户画像存KV，历史对话存向量库。检索时结合元数据喂给Agent。
9. AI开发心得：用Agent自动写代码、Debug或测试，重点讲清解决的痛点和提效成果。
10. Agent预期：目前仍初级，有幻觉。未来期望具备长期记忆、跨App操作，成个人数字助理。

字节，腾讯，蚂蚁，阿里，华为这些公司的辅面做很多了  基本上都能顺利通过的没把握的可以兜一下底，可以问问。
