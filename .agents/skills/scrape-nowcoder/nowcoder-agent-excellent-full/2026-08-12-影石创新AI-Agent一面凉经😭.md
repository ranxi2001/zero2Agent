下面是面试问题：

1. 简单介绍一下自己的经历，以及为什么选择AI Agent方向？
2. 平时开发过程中主要使用哪些 AI Coding 工具？比如 Claude Code 这类工具，通常有哪些使用习惯？
3. 如何理解 Spec Coding 和 Harness？你认为 Harness 为什么能够提升 Agent 完成复杂任务的能力？
4. 如果让你从零开始设计一个 Agent 系统，你认为需要包含哪些关键模块？
5. Agent 在执行任务时，如果调用外部工具或 API 出现超时、异常等情况，一般应该如何设计容错机制？
6. 是否考虑过让大模型参与错误分析和自动恢复？这种方案有什么优缺点？
7. Agent 中的短期记忆和长期记忆分别有什么作用？通常会如何实现？
8. 在 Agent 开发过程中，上下文为什么需要进行压缩？压缩后可能导致信息缺失，应该如何解决？
9. Prompt 优化除了添加规则约束之外，还有哪些常见的方法？你在实际使用中有哪些经验？
10. 当模型出现幻觉问题时，一般有哪些解决思路？
11. 如果 Token 消耗突然增加，你会如何定位原因并进行优化？
12. 你有没有设计过 Agent Skill？一个 Skill 从设计到上线通常需要考虑哪些因素？如何判断效果好坏？
13. 介绍一下之前做过的相关项目，这个项目是完全自主开发，还是基于已有开源方案进行改造？
14. 在项目过程中遇到过哪些比较困难的问题？你主要负责哪些部分？最后取得了什么结果？
15. Java线程池的核心参数有哪些？线程提交任务后的执行流程是怎样的？
16. 如果让你重新设计一个线程池，你会重点考虑哪些问题？
17. JVM加载一个class文件的完整过程是什么？
18. MySQL中的undo log、redo log和binlog分别解决什么问题？它们之间有什么区别？
19. 什么是MySQL两阶段提交？为什么需要这个机制？
20. 算法题：合并两个有序数组
21. 反问环节

整体面试感觉比较偏 AI Agent + 后端基础能力结合，前半部分主要考察对Agent体系的理解，后半部分又回到了Java和数据库基础，项目部分虽然也会问，但没有特别深挖业务细节。
